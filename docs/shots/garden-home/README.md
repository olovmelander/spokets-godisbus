# Gården — public viewport review

These captures show the generic public buildings and stand-in figures at the playhouse stretch of
Chapter 1. They were made from the actual renderer with `tests/browser/garden-home.mjs` on High.
Private home models and their reference comparisons remain outside public git; the detailed assets
are in [private asset PR #1](https://github.com/olovmelander/spokets-godisbus-familj/pull/1).
