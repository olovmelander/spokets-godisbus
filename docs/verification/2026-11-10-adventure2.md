## The three speech rules

- **Finish the line.** A pending line/event and its flags wait for the current bubble and recording. There is no
  ten-second bypass. Continue cannot cut a playing recording. Pause and hiding the page suspend playback; returning
  resumes it only when no other pause is active. Long-recording and full-story listener tests cover this.
- **Keep subtle life.** Body and face time continues while the player reads; story events and simulation time remain
  held. Visual events follow actual simulation steps, including low frame rates and Lugnt. Pause freezes all clocks.
- **Move only the speaker's mouth.** Runtime face motion uses the line's Swedish text and the recording's playback
  position when available, with silent text timing otherwise. All seven private faces were inspected without changing
  the private models. Speaker/listener, playback-progress, blink and Pause checks accompany the browser motion checks.
  No new voice recordings were generated; the voice script was regenerated to match the final lines.
