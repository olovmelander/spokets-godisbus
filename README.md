# Elof och det stora godisäventyret

A 2.5D adventure for Elof, set in and around Bredbyn in Ångermanland. Pappa Emil's carved wooden ghost comes
alive, steals Elof's giant bag of Saturday sweets and leaves a trail of candy behind it. Elof follows it through
the yard, the spruce forest, the forest brook and the misty bog, all the way up the mountain, to find out *why*.

- **Status:** planning. Nothing is built yet.
- **The plan:** [`docs/game-plan.md`](docs/game-plan.md), covering the design, the art direction after
  *Unravel*, the technology (Three.js r186, Vite, GitHub Pages) and the delivery stages. Its §0 holds the open
  questions.
- **Site** (after the first deploy): https://olovmelander.github.io/spokets-godisbus/
